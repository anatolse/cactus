# Cactus DSL — Rust Backend

**Status: Planned**

This backend will generate Rust code from the Cactus DSL decorated AST. It is not yet implemented.

## Planned Features

- Rust ECS code generation (likely targeting `bevy_ecs` or `hecs`)
- Raylib-rs integration for rendering
- `persist` field serialization via `serde`
- `sync` field network replication stubs
